PR Review Practice
This file is a temporary document used to practise the GitHub pull request workflow.
Review checklist
- [ ] Read the pull request description.
- [ ] Check the changed files and diff.
- [ ] Confirm the change matches the stated purpose.
- [ ] Look for spelling, formatting, and clarity issues.
- [ ] Leave specific, actionable review feedback.
- [ ] Verify the requested checks have passed.
