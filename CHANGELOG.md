# Changelog

All notable changes to KeyClean will be documented in this file.

## [0.1.0] - 2026-10-24
### Added
- Core DSP pipeline featuring STFT spectral flux and high-frequency energy ratio metrics.
- Rolling Median Absolute Deviation (MAD) robust Z-score detection engine.
- Hysteresis double-thresholding mode for switch bottoming noise envelope capture.
- Raised-cosine S-curve crossfade inpainting algorithm.
- Interactive web interface with live audio waveform comparison player.
- Standalone CLI demo runner and hyperparameter grid search optimizer.
